[h1]Bonbon Tree Boost[/h1]

Configure the Bonbon Tree (Space Tree) nectar production, growth speed, and fertilizer consumption to suit your gameplay needs.

[h2]Features[/h2]
[list]
[*][b]Wild trees[/b] — Nectar production, trunk growth, and branch growth multipliers
[*][b]Domesticated trees[/b] — Nectar production, trunk and branch growth, and fertilizer consumption
[*][b]Production balance[/b] — Choose whether wild or domestic trees produce more (or equal)
[*][b]Production advantage[/b] — When one type is favoured, how much more it produces
[*][b]Do not harvest branches[/b] — Option to stop dupes harvesting branches for wood
[*][b]Works with existing saves[/b] — Changes apply after a restart
[/list]

[h2]How to Use[/h2]
[olist]
[*][b]Open Mod Options[/b] - Main Menu → Mods → Bonbon Tree Boost → Options (gear icon)
[*][b]Configure Wild Trees[/b] - Set nectar production, trunk growth, and branch growth multipliers
[*][b]Configure Domesticated Trees[/b] - Set nectar production, growth rates, and fertilizer consumption
[*][b]Set Production Balance[/b] - Choose Wild Advantage, Equal, or Domestic Advantage
[*][b]Restart Game[/b] - Changes require a game restart to take effect
[/olist]

[h3]Tips[/h3]
[list]
[*]Set fertilizer consumption to 0.0 to disable fertilizer requirements for domesticated trees
[*]Use the Production Balance setting to control which tree type produces more
[*]Branch harvesting can be disabled if you only want nectar production
[*]Growth rate changes affect how quickly trees mature
[/list]

[h2]Compatibility[/h2]
[list]
[*][b]Oxygen Not Included[/b] - Build 700386 or later
[*][b]Mod API[/b] - Version 2
[*][b]DLC Support[/b] - Requires The Frosty Planet Pack (contains Space Trees)
[*][b]Other Mods[/b] - Compatible with most mods
[/list]
