PART 1: UNDERSTANDING THE SYSTEM

The Interlock Principle

The boiler only fires when:

  1. The programmer is on for that channel,
  2. A thermostat is calling for heat, AND
  3. A valve has confirmed it is open (via auxiliary switch)

No open valve = No boiler firing (this is the safety interlock)

⚡ CRITICAL: Grey Wire Variations

The grey wire can be wired in two different ways depending on who installed the system:

Wiring MethodGrey Wire Connected ToEffect on Manual Override
Method APermanent Live (L)Manual lever ALWAYS works
Method BProgrammer Channel OutputManual lever ONLY works when programmer channel is ON

Why This Matters for Troubleshooting

If grey is on Permanent Live:

  • Manual lever will open valve AND fire boiler (aux has power)
  • If manual works → motor or upstream wiring fault
  • If manual doesn't work → aux switch fault

If grey is via Programmer:

  • Manual lever will physically open valve but WON'T fire boiler unless programmer channel is ON
  • Must have programmer channel ON to test aux switch
  • Can cause confusion - "manual doesn't work" might just mean programmer is off

How to Check Grey Wire Source

  1. Set programmer to OFF for that channel
  2. Measure voltage: Grey to Neutral
  3. 230V present = Grey is on Permanent Live
  4. 0V = Grey is via Programmer (turn channel ON to get 230V)

How the Valve Operates

CALL FOR HEAT: Thermostat calls → 230V on BROWN → Motor runs → Valve opens ↓ Aux switch closes ↓ 230V on GREY → passes through aux → 230V on ORANGE ↓ BOILER FIRES SATISFIED: Thermostat satisfied → 0V on BROWN → Spring closes valve → Aux opens → Boiler stops

Step-by-Step Diagnostic Procedure

STEP 1: Verify Power Supply

TestMethodExpected
Main powerMeasure L to N at wiring centre230V

If no power: Check fused spur, consumer unit breaker

STEP 2: Check Programmer Outputs

Set programmer to HW ON and CH ON

TestMethodExpected
HW outputHW terminal to N230V when HW on
CH outputCH terminal to N230V when CH on

If no output when ON: Programmer faulty

STEP 3: Check Thermostats

Room Thermostat:

  • Turn UP above room temperature (should click)
  • Measure input to N = 230V
  • Measure output to N = 230V when calling

Cylinder Thermostat:

  • Turn UP above tank temperature, or remove stat from cylinder
  • Measure input to N = 230V
  • Measure output to N = 230V when calling

If 230V in but not out when calling: Thermostat faulty

STEP 4: Check Valve Motor Circuit (BROWN wire)

TestExpectedIf Fail

Valve movement within 15 secMotor runs, lever movesMotor failure

Motor Failure Confirmation: 230V on brown but no movement = Motor dead. Replace actuator head (not whole valve body), or synchron motor to keep parts cost down.

PART 3: CONTINUITY TESTING

⚠️ POWER MUST BE OFF FOR ALL CONTINUITY TESTS

Testing a Wire

  1. Disconnect both ends
  2. Meter to continuity (Ω)
  3. Touch probes to each end
  4. Beep/low Ω = Good
  5. No beep/OL = Broken

Testing a Thermostat

ConditionExpected
Turned UP (calling)Continuity
Turned DOWN (satisfied)No continuity

Testing a Valve Aux Switch

  1. Disconnect orange wire
  2. Manually open valve
  3. Check continuity: Orange terminal to Grey terminal
  4. Open position = Continuity
  5. Closed position = No continuity
