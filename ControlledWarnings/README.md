# Controlled Warnings

Adds enhanced alerts for critical situations that can be easily missed in the standard game notifications.

## Features

- **Trapped Duplicant Alerts** - Adds a left-side notification when a dupe gets trapped
- **Critical Escalation** - Alert escalates to critical (red) if a trapped dupe is also suffocating
- **Click to Jump** - Click the notification to center camera on the trapped dupe
- **Pause on Critical** - Optional game pause when a critical alert triggers
- **Configurable Cooldowns** - Prevents alert spam with adjustable cooldown periods

## Mod Options

- Enable/disable trapped alerts
- Persistent or auto-expiring alerts
- Enable/disable critical escalation
- Pause on critical option
- Adjustable alert cooldown

## Compatibility

- **Suppress Notifications** - Fully compatible
- **DLC Support** - Works with base game and all DLC

## Performance

Minimal impact - hooks into the existing trapped duplicant diagnostic cycle.

## Installation

### Steam Workshop (Recommended)
Subscribe on [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=XXXXXXXXX) and enable in the Mods menu.

### Manual Installation
1. Download the [latest release](https://github.com/MiserableGamer/ONI-Miserable-Mods/releases)
2. Extract to: `%USERPROFILE%\Documents\Klei\OxygenNotIncluded\mods\Local\ControlledWarnings\`
3. Enable in the Mods menu
