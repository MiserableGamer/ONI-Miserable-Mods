[h1]High Precision Temperature FIXED[/h1]

Displays temperatures with 4 decimal places instead of the default 1 decimal place. A fixed and updated version of the original High Precision Temperature mod.

[h2]Features[/h2]
[list]
[*][b]High Precision Display[/b] - Shows temperature values like 25.1234°C instead of 25.1°C
[*][b]All Units Supported[/b] - Works with Celsius, Fahrenheit, and Kelvin
[*][b]Robust Patching[/b] - Uses a more reliable patching approach that should survive future game updates
[/list]

[h2]Why This Mod?[/h2]

The vanilla game restricts temperature display to 1 decimal place for most values (only showing 4 decimals when temperature is below 0.1). This can make precise thermal management difficult.

The original "High Precision Temperature" mod stopped working after game updates changed the internal method structure. This version targets the correct method and should survive future updates.

[h2]Use Cases[/h2]
[list]
[*][b]Thermal Management[/b] - See exact temperatures for precise heat exchange calculations
[*][b]Debugging[/b] - Identify small temperature changes that would otherwise be hidden
[*][b]Mod Development[/b] - Useful for testing thermal mechanics in custom buildings
[/list]

[h2]How to Use[/h2]

Just install and enable the mod - no configuration needed! All temperature displays in the game will automatically show 4 decimal places.
