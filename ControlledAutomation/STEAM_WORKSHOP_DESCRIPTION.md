[h1]Controlled Automation[/h1]

Adds high/low threshold controls and automation signal inversion options to storage buildings and sensors.

[h2]Features[/h2]

[h3]Storage Thresholds[/h3]
Adds configurable high/low threshold sliders (like Smart Battery) to storage buildings that don't already have them, such as Smart Storage Bin and Refrigerator.

[h3]Automation Signal Inversion[/h3]
Adds an "Invert Signal" checkbox to storage buildings, sensors, and various other automation-enabled buildings, allowing you to swap Green/Red automation signals without needing a NOT gate.

[h3]Adv. Thermo Sensor[/h3]
Adds a new temperature sensor building with range-based triggering, and a delay buffer:
[list]
[*]Set a center temperature and define a range above/below
[*]Triggers when temperature is inside (or outside, when inverted) the defined range
[*]Supports typed input and nudge buttons like vanilla sensors
[*]Available in the Automation build menu
[/list]

[h2]Options[/h2]
[list]
[*][b]Enable Storage Thresholds[/b] - Enable/disable threshold sliders on supported buildings
[*][b]Enable Automation Inversion[/b] - Enable/disable signal inversion on all supported buildings
[/list]

[h2]Why Use Signal Inversion?[/h2]

Normally, to invert an automation signal you need to add a NOT gate, which:
[list]
[*]Takes up space
[*]Costs materials
[/list]

With this mod, you can simply check the "Invert Signal" box on the building itself!

[h2]Compatibility[/h2]
[list]
[*]Works with base game and all DLCs
[*]Compatible with [b]Big Storage[/b] mod - threshold and inversion controls work on Big Refrigerator, Big Smart Storage Bin, and Big Reservoirs
[*]Compatible with [b]Ronivan's Legacy[/b] mod - inversion controls work on supported buildings
[*]Compatible with [b]Multiple Elements Sensors[/b] mod - inversion controls work on all multi-element sensors
[*]Compatible with most other automation mods
[/list]
