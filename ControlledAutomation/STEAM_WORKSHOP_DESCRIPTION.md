[h1]Controlled Automation[/h1]

Adds high/low threshold controls and automation signal inversion options to storage buildings and sensors.

[h2]Features[/h2]

[h3]Storage Thresholds[/h3]
Adds configurable high/low threshold sliders (like Smart Battery already has) to:
[list]
[*][b]Smart Storage Bin[/b] - Set custom fill thresholds
[*][b]Refrigerator[/b] - Set custom fill thresholds  
[/list]

[h3]Automation Signal Inversion[/h3]
Adds an "Invert Signal" checkbox to 40+ buildings, allowing you to swap Green/Red automation signals without needing a NOT gate.

[b]Storage Buildings (already have thresholds, adds inversion):[/b]
[list]
[*]Smart Battery
[*]Liquid Reservoir
[*]Gas Reservoir
[*]Radbolt Chamber
[/list]

[b]Producer Buildings:[/b]
[list]
[*]Critter Trap
[*]Fish Trap
[*]Airbourne Critter Trap
[*]Diamond Press
[/list]

[b]Sensors:[/b]
[list]
[*]All liquid/gas/solid conduit sensors
[*]All environmental sensors (temperature, pressure, light, etc.)
[*]All logic sensors (timer, counter, critter count, etc.)
[*]Meter valves (liquid, gas, solid)
[*]Starmap Location Sensor
[/list]

[b]Other Buildings:[/b]
[list]
[*]Geotuner
[*]Materials Study Terminal
[/list]

[b]Special:[/b]
[list]
[*][b]Rocket Platform[/b] - Has two independent inversion options for each automation output
[/list]

[h2]Options[/h2]
[list]
[*][b]Enable Storage Thresholds[/b] - Enable/disable threshold sliders on supported buildings
[*][b]Enable Automation Inversion[/b] - Enable/disable signal inversion on all supported buildings
[*][b]Reduced Smart Storage Power[/b] - Reduces Smart Storage Bin power consumption to 20W
[/list]

[h2]Why Use Signal Inversion?[/h2]

Normally, to invert an automation signal you need to add a NOT gate, which:
- Takes up space
- Costs materials
- Can cause brief false signals on game load

With this mod, you can simply check the "Invert Signal" box on the building itself!

[h2]Compatibility[/h2]
[list]
[*]Works with base game and all DLCs
[*]Compatible with most other automation mods
[*]Saves are compatible - settings are stored per building
[/list]
