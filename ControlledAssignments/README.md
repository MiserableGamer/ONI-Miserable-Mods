# Controlled Assignments

Makes showers and sinks assignable to individual duplicants, just like beds and toilets.

## Features

- **Assignable Showers** - Assign specific duplicants to showers, or leave them public for anyone to use
- **Assignable Sinks** - Assign specific duplicants to wash basins, wash sinks, and hand sanitizers
- **Mod Compatible** - Automatically works with modded showers and sinks that use vanilla components

## How to Use

1. **Build a shower or sink** - Place any shower or sink building
2. **Select the building** - Click on the building to open its details panel
3. **Assign a duplicant** - Use the assignment dropdown to assign a specific duplicant, or leave as "Public"

### Tips

- Unassigned buildings default to "Public" so all duplicants can use them
- Works the same way as bed and toilet assignments

## Installation

### Steam Workshop (Recommended)
Subscribe on [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3666034876) and enable in the Mods menu.

### Manual Installation
1. Download the [latest release](https://github.com/MiserableGamer/ONI-Miserable-Mods/releases)
2. Extract to: `%USERPROFILE%\Documents\Klei\OxygenNotIncluded\mods\Local\ControlledAssignments\`
3. Enable in the Mods menu

## Compatibility

- **Oxygen Not Included** - Build 700386 or later
- **Mod API** - Version 2
- **DLC Support** - Works with base game and all DLC (including Bionic Booster Pack)
- **Other Mods** - Compatible with most mods; automatically supports modded showers and sinks

## Performance

**Minimal Performance Impact**
- Only runs when buildings spawn — no per-frame overhead
- Uses standard game assignment system
